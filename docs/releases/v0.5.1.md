# Open Family Office v0.5.1

v0.5.1 is a distribution and launch-infrastructure patch on top of v0.5.0. It does not change the household accounting model or introduce new financial recommendations.

This draft release is prepared from the same versioned source that will be built for PyPI and referenced by the MCP Registry.

## Distribution

- Adds a PyPI-friendly `open-family-office` command while preserving the short `ofo` CLI.
- Adds Trusted Publishing automation for PyPI using GitHub OIDC — no long-lived PyPI token.
- Adds official MCP Registry metadata in `server.json`.
- Adds GitHub OIDC publication to the MCP Registry after the matching PyPI version becomes available.
- Pins and checksum-verifies the MCP Publisher used in CI and release workflows.
- Adds a prepared GitHub Pages deployment workflow for the synthetic public demo.

## Release integrity

The release pipeline now checks that these versions stay identical:

- `pyproject.toml`
- `src/open_family_office/__init__.py`
- `package.json`
- `package-lock.json`
- `server.json`
- the MCP package version inside `server.json`

CI also validates `server.json` with the official MCP Publisher and smoke-tests both installed CLI names from a built wheel.

## Install

Until the first PyPI Trusted Publisher run completes:

```bash
uvx --from git+https://github.com/JamesbbBriz/open-family-office.git ofo demo --open
```

After PyPI publication:

```bash
uvx open-family-office demo --open
```

or:

```bash
uv tool install open-family-office
ofo --version
```

## MCP boundary

The MCP server remains optional, local and read-only. It requires an explicitly authorized `OFO_WORKSPACE` and does not place trades, move money or perform bank logins.
